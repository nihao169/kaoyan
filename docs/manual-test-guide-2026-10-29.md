# 教师资料与 AI Agent：人工验证链路

更新：2026-10-29。此清单用于亲自测试，不表示所有文件类型、教学内容和边界场景均已人工验证。

## 准备

打开 http://127.0.0.1:5173。teacher / student / admin 的本地演示密码均为 `Zhixing2026!`。教师和学生使用不同浏览器配置文件或不同浏览器，避免同一会话互相替换。账号前后空格会去除，密码区分大小写。

2026-10-29已按要求清空旧资料、题目、作业和学习记录，保留账号、班级与模型配置。先上传下面的独立讲义，再生成题目并发布新作业。

## 1. 上传与一次启用

1. teacher → 教学内容 → 导入新资料 → 上传文件。可先用 `测试导入资料/政治模拟讲义_实践认识与辩证方法.md`，再换自己的文字PDF或DOCX。此讲义只有正文和虚构案例，不附预置试题或答案。
2. 等待解析和索引就绪，检查正文、章节或页段。PDF/DOCX能查看原页和原文件；TXT/MD按真实段落定位，无虚构页码，可下载原始文本。
3. 无需预选知识点。默认政治、12题（6单选4多选2分析题）。先用1/1/1便于快速核对，单批总数须1至30。
4. 可选择章节及已启用补充资料。一次点“启用并生成”，无需填写审核描述或再次发布。
5. 应显示知识提取、出题、校验等阶段。刷新仍看到同一任务；失败显示原因和重试按钮，不得用演示题伪装成功。
6. 核对知识卡、题干、选项、答案、解析、四级提示和分析题评分要点。引用能定位原文；本批覆盖说明不能宣称覆盖整本书。

限制：50MB、1000页；扫描页不做OCR，会明确提示。DOCX需要LibreOffice。TXT/Markdown使用UTF-8编码。

## 2. 布置作业与学生草稿

1. teacher → 作业与批阅 → Agent生成题库。原演示题、学生个人练习不应混入此表。
2. 展开核对题目和引用；需要时编辑或停用题目。勾选 → 布置所选题目 → 填名称、选班级，可选截止时间 → 发布作业。
3. student → 我的作业，应看到该班级作业。无需先设置目标或做基础诊断。
4. 开始作业，逐题填答案与思考过程。切题前保存，停留时自动保存；刷新应恢复草稿。整组未完成时提交，应提示缺少第几题。
5. 单选故意选错；多选故意错选并漏选；分析题填写真实分析。“学习提示”应定位帮助区，使用提示应留痕。
6. 提交整组后答案冻结。重复提交不能重复计分。不会自动错题诊断或自动生成个人练习。

## 3. AI初评与正式评分

1. 客观题显示“系统已判分”。分析题显示“AI初评中”→“AI初评待教师确认”。建议分与正式分分开，未确认不能显示教师已评分。
2. teacher → 作业与批阅 → 对应作业“查看作答 / 批阅”。操作列可找到查看作答、确认评分；异议记录可找到处理入口。
3. 打开分析题，核对AI分项、总分和依据。可点“确认AI初评”，或修改分项及意见后保存。
4. student刷新后才看到正式成绩；仅AI建议不能计入正式总分、独立掌握或已确认错题。
5. 学生提出异议，教师处理并修订评分。保留评价历史，同步错题与后续状态。

## 4. 错题证据与手动诊断

1. student → 错题诊断，直接显示完整原题、全部选项、你的选择、标准答案、错选漏选、原始过程、提示记录、原文知识卡和对应作业。
2. 点“AI诊断”后才调用模型。未点击前无结果；刷新后已完成结果保留。
3. 核对是否分析实际错误、引用上传原文。过程简略时不能断言心理错因，应说明可能性并允许澄清。
4. 无需强行选择六类错因，无需再次提交审核。

## 5. 针对性练习与再验证

1. 诊断完成后点“生成针对性练习”。未点击前无新题；重复点击或重试不能重复创建同一组。
2. 客观错题默认3道同类型，分析题默认1道。核对是否针对实际错误、有授权原文，不能只是原题选项换序。
3. 开始练习，逐题作答，提交整组。草稿、原始错题和练习结果保留；教师原作业及公共题库不变。
4. 比较原错误和新表现。独立正确后才有巩固证据与复习安排，阅读建议不当作掌握。
5. 教师打开原作答的“补学、验证与AI证据”，应能追踪诊断、个人练习和复习。

## 6. 失败与权限

分别测试扫描PDF、超限文件、无关材料、来源冲突、模型超时、中断重试、来源撤回、另一学生访问作答、另一班级访问作业。要求明确报错、保留草稿及原件，不制造引用或成绩。来源撤回后不能继续生成新内容，历史版本引用保留。
