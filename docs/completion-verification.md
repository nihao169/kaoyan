## 已实现

- 六模块、18 张知识卡、60 道原创样例题；初始化可重复执行，不改写历史学习记录或已发布资料。
- 七份原创 DOCX 与对应 PDF，包括修订版，均已用 LibreOffice 渲染并逐页检查；另有无答案、相似概念、冲突和提示注入边界样例。
- PDF、DOCX、TXT、Markdown 真实导入；DOCX 转固定版式 PDF；原件受权限保护；原页、提取文字对照及页级引用高亮；失败与重试；教师核对后提交审核。
- 关键词与本地多语言向量融合检索；模型权重实际下载、SHA256 核验、本地 CPU 推理。模型提交为 `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`，输出 384 维向量。
- 检索前权限及版本过滤、索引状态和重建、历史版本追溯。没有共享检索缓存，不存在未按权限隔离的缓存复用。
- 知识点证据状态、每日时间预算与目标分数侧重、薄弱线索及前置关系、练习补充、错因修订历史和重新匹配知识卡。
- 阅读知识卡、提示使用、原始作答、独立新题验证、复习分别记录；教师串联查看学习链与 AI 建议。
- DeepSeek 服务端适配，提供当前题目答疑、四级提示、候选错因、分析题辅助评价和可编辑教案；LangGraph 检查点、引用与提示边界审核、失败重试、调用期间撤权再检查。
- 学生申请教师帮助、教师回复和处理状态；AI 请求与成功提供帮助分开记录，失败不消耗提示级别；AI 候选错因须确认，AI 建议不直接写入正式成绩；教案不自动发布。
- 管理员脱敏配置状态、真实连接测试；调用次数、耗时、token 与带价格版本的费用估算；Key 仅从服务端环境配置读取。

## 等待填写 Key 的验收

在项目根目录 `.env` 的 `MODEL_API_KEY` 填入实际密钥，重启 API 和 worker。不要将密钥写入源码或发送到聊天。

管理员可先在“AI 服务状态”进行真实连接测试，再执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/test-real-ai.ps1
```

脚本在独立数据库中，通过实际页面测试答疑、四级提示、错因、辅助评价、教案和原页引用；不将受控适配器结果当作真实调用。真实记录输出到 `.runtime/real-ai-acceptance.json`，并标记人工质量复查仍需完成。应逐条核对解释支持性、提示边界、评价维度及失败情况；不通过则修复后重验。

## 草稿保存冲突修复

修复用户实际遇到的“空答案提交失败后持续提示草稿版本变化”：移除提交前未同步版本的重复 PATCH，所有保存统一读取服务器当前版本，并串行补存请求期间新增的输入。提交失败仍保留最新保存状态；提示或 AI 元数据更新不会再造成旧版本循环保存。

服务器答案确被另一页面修改时，保留当前输入并显示冲突，不静默覆盖；读取服务器草稿需用户明确操作。前端生产构建通过，核心浏览器回归由 6 条扩充至 10 条并全部通过，新增覆盖空提交后续写、自动保存与手动保存交叠、提示版本变化及跨页面冲突。
