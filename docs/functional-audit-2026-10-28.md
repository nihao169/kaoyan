# 角色功能实测清单

日期：2026-10-28。验证对象：本机知行研学平台。

本清单按用户实际可操作的页面统计能力，不将数据表、架构预留接口、受控模型测试算作已交付业务功能。

- 检查开始时，API、前端、worker 均已停止；本次已用启动脚本恢复运行。
- 当前地址为 http://127.0.0.1:5173，API 为 http://127.0.0.1:8000。
- 实际登录 teacher、student、admin，检查 12 个页面，没有捕获到 JavaScript 页面异常。
- 当前教师可见 1 名学生，提交作答 0 次，待评分析题 0 份，异议 0 条。
- 当前 6 份原创演示资料均为草稿，没有已发布教学内容。
- 当前学生已有目标，但诊断为空、学习任务为空、错题为空、复习为空、学习记录为空。
- 学生实际点击“开始基础诊断”，接口返回 409 / CONTENT_REQUIRED：“暂无审核发布的诊断题，请教师先发布演示内容”。请求失败后没有创建有效诊断。
- AI 就绪状态为 not_configured，不能进行真实模型辅导。

因此，当前演示库尚不能直接体验完整答题流程。此前隔离测试中的发布、作答和评分记录不在此演示库中。

## 教师账号 teacher

| 操作 | 实际结果与边界 |
|---|---|
| 登录、退出 | 可用 |
| 教学概览、班级与作答 | 可查看授权学生、提交次数、待评数和累计得分；当前演示库只有 1 名学生，尚无作答 |
| 查看作答详情 | 有作答后可查看原始答案、思考过程、提示记录、来源和评价历史 |
| 分析题评分 | 可按要点输入分数、评语，保存正式评价；浏览器闭环验证通过 |
| 处理学生异议 | 可复核、修订评分并保留历史；浏览器闭环验证通过 |
| 导入教学资料 | 支持输入文本及上传 UTF-8 TXT/Markdown；不支持 PDF、DOCX、图片解析 |
| 维护知识卡与题目 | 可录入、修改草稿，支持单选、多选、分析题和四级人工编写提示 |
| 审核发布资料 | 可提交审核、发布、退回、撤回，发布需要关联知识卡和题目；不是上传即自动可学习 |
| 修订资料 | 可创建新版本并编辑，历史作答引用旧版本 |
| 自主布置任务/作业 | 未实现：没有选学生、选题、截止日期、发布作业功能 |
| 管理学生账号与班级 | 未实现完整管理：教师只能查看授权学生；不能创建/删除学生、调班、创建班级或重置密码 |
| AI 备课、AI 批改 | 当前不可用：无真实模型配置，也没有完整 AI 备课业务页面 |

## 学生账号 student

| 操作 | 实际结果与边界 |
|---|---|
| 登录、退出、修改目标 | 可用，可设置年份、分数、每日时间 |
| 基础诊断 | 教师发布内容后可用；当前演示库被未发布内容阻断 |
| 查看学习任务 | 完成诊断后系统按规则生成；不是接收教师手工布置的作业 |
| 答题、填写思考过程、保存草稿 | 有任务后可用，刷新及重新登录后恢复，浏览器闭环验证通过 |
| 客观题自动判分 | 可用，单选/多选按审核答案规则判分 |
| 提交分析题 | 可用，提交后等待教师评分，不自动产生正式成绩 |
| 查看四级提示 | 练习中支持，内容由教师预先编写；不是实时 AI 生成，诊断中禁用 |
| 错题与补学 | 有错误或提示作答后出现，可确认错因、阅读知识卡、打开来源并进行另一道新题验证；新题不足会显示缺口 |
| 复习计划 | 符合独立验证条件后生成第 1、3、7 天安排；不是登录后即有任务，未到期不能提前完成 |
| 学习记录、教师评分、异议 | 有对应记录后可查看并提出异议，浏览器闭环验证通过 |
| 上传个人资料 | 未实现；学生没有资料上传入口，直接进入内容管理也被阻止 |
| 接收教师发布的作业 | 未实现，因为教师发布作业功能尚未建设 |
| 实时 AI 问答 | 当前不可用，无真实模型配置；模型适配器受控测试不等于真实接通 |
| 自由选题/组卷、完整课程学习 | 没有独立题库刷题、组卷、视频课程等页面 |

## 管理员账号 admin

| 操作 | 实际结果与边界 |
|---|---|
| 查看账号 | 可查看姓名、账号、角色和状态 |
| 创建账号 | 可设置初始密码、角色、从已有班级中选择所属班级；已实际通过页面创建新学生并成功登录 |
| 导入、编辑教学内容草稿 | 可用，发布需教师角色 |
| 独立评分、审核发布 | 单独管理员角色没有此权限 |
| 停用/删除/编辑账号、重置密码、调班 | 页面和配套业务操作未实现；列表显示“正常”不代表有停用管理功能 |
| 创建班级、完整机构管理 | 未实现，仅有现成演示班级与机构 |
