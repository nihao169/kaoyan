## 范围与限制

支持文字PDF、DOCX、UTF-8 TXT/Markdown，50MB、1000页。PDF/DOCX原页定位沿用真实固定版式；TXT/MD使用章节段落，保留原始上传字节。扫描页无OCR；DOCX依赖LibreOffice。

本次真实模型闭环使用小型Markdown样本。PDF/DOCX解析、原页和异常由已有后端回归验证，未对每一种格式都重复真实模型全链路；没有用1000页整本教材证明教学覆盖。提取最多16个代表页段，再按知识点检索，因此仅声明本批范围。

页面自动测试使用Playwright驱动实际Edge浏览器，不等同于逐按钮的原生computer-use人工操作。当前仍是本机SQLite单worker应用，尚未验证持续多人高并发。前端构建有包体大小提示，不影响构建通过，但后续可以按页面拆包优化初次加载。
