# 项目学习流程

首次学习（chapter）、期末复习（final）、考研学习（kaoyan）都保存到服务端。创建项目后先准备必备资料。首次学习需要本章讲义，期末复习需要讲义和已确认的考试范围，考研学习需要目标年份考纲和教材。往年真题到考研项目的真题阶段才必填。

学生从项目的「与助教学习」进入。资料就绪后，页面按场景提供大纲、教学、理解检查或复习操作。学生点击时，服务端向 DeepTutor 提交相应阶段的教学提示词。DeepTutor 原生 Mastery Path 保存大纲、题卡、掌握证据和复习安排。关闭页面后可以继续。今日学习和学习报告读取同一学习路径。

首次学习在大纲确认后安排今日任务。继续学习会按计划逐项讲解和检查。完成计划或用完时间预算后收尾。查看小结或进入集中练习时可暂停今日计时，当前题卡可在继续学习后作答。

期末的摸底和综合复测各安排最多三题，考研每个专题安排一次检查。助教讲评后，下一题等学生点击继续再生成。

## 资料和功能联动

- 资料齐全且索引就绪后开放阶段操作与自由追问。待答题卡期间也可以追问，提问与提交答案分别操作，追问不会登记为作答或推进阶段。支持教师已启用课程资料、个人上传、粘贴文本和年度资料导入。期末范围可以从 Markdown 标题选择、填写说明或指定上传的范围文件。
- 年度资料支持直接导入 JSON，也可上传文字型 PDF、DOCX、TXT、Markdown，由后台提取草稿。核对原文并确认使用权限后入库。历年真题原卷与模考沿用既有测评快照。真题添加不改专题绑定，模考交卷前暂停助教、资料和草稿读取。
- 精读使用原生 Immersive Reading，会话按资料分别保存；可从“返回引导学习”回到项目路径。
- 选定笔记作为原生 Notebook 引用交给助教讨论大纲，先展示建议、确认后修改。原笔记和闪卡保留。
- 三个场景的集中练习均可按有效范围生成 1–10 道单选、多选或分析题。新练习不限时，自动保存草稿，整组交卷后查看题目反馈。历史章节练习保留原时限。集中练习作答不更新引导学习的掌握状态。
- 在「与助教学习」的到期复习区开始当前项目的复习。已纳入今日任务的复习从今日任务继续。已提交的复习可在「学习报告 → 作答记录」选「复习」回看；旧版教师作业复习不迁入。
- 学习报告按项目汇总已提交的助教检查、练习和整卷记录。错题诊断中的「自主学习」呈现答错或明确未达标的题，学生可以手动请求 AI 诊断。自主记录不会同步到教师作业或教师评分。
- 更新后需执行数据库迁移 `c3612e69a245`，并重建 DeepTutor 集成镜像以启用旧助教作答的查询。桥接尚未更新或不可用时，报告仍可显示平台保存的整卷记录。
- 政治课程保留既有政治专项测评、年度模拟资料。通用课程不展示政治出版社书目，不允许添加政治模拟资料。Full Book 生成界面不在本次接入范围。

## 历史、权限与恢复

旧项目第一次进入需要确认场景、课程与目标。历史任务、笔记、成绩、证据保留；确认后的项目不再由旧任务引擎安排日程与补学。历史学习任务只读，测评继续保留。旧版客户端未确认的项目暂保留兼容接口，主界面统一走确认入口。

每个项目按资料范围绑定原生路径。调整目标或时间预算保留同一路径和有效证据；资料范围变化建立新绑定，旧绑定保留，不把撤回资料的学习现场带入新范围。归档后只读。每次读写检查用户、资料权限和独立模考限制。

学习请求先持久化到平台队列，再由工作线程在数据库事务外调用原生接口。失败恢复复用同一提交标识；原生题卡和暂停澄清分别使用对应回答协议。原生会话执行失败时显示错误，保留已有会话和证据。HTTP 超时不视作教学成功。

## 运行与验证

数据库迁移 `75d1c82fae39` 增加今日计划和阶段检查记录。正式切换前用 `scripts/backup-v2.ps1 -Release` 做一致性备份。重新构建 DeepTutor 集成镜像后更新桥接容器，并执行 `scripts/start-release-v2.ps1`。联调时将新版前端构建输出到隔离目录，运行中的 5183 会直接读取 `frontend/dist`。

自动检查：后端 `test_project_learning.py`、`test_v2.py`、`test_v2_native_storage.py`、`test_mastery_reviews.py`、`test_v2_migration.py`；前端 `npm run test:e2e:v2`、`npm run test:api` 和 `npm run build`。浏览器契约测试与真实模型验证分开执行。

隔离真实服务验证：先准备 `tutor-native-preview-*` 容器及其模型/嵌入配置，再运行 `scripts/verify-project-learning.py <preview目录>`。附加 `--teaching` 验证大纲保存、教学、理解检查及回答。该脚本仅接受工作区 `.runtime` 下的预览目录，使用独立原生身份，不使用正式项目。
